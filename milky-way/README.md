# 01 우리은하 — 인터랙티브 과학 수업자료

중학교 2학년 과학 **‘별과 우주’** 단원 중 **우리 은하**를 학생이 직접 조작하며 탐구하는 웹 시뮬레이터입니다.
React + Vite로 만들었고, 빌드하면 **사진·코드가 모두 들어 있는 HTML 파일 하나**가 만들어집니다.
그래서 GitHub Pages에 올려도 되고, 인터넷이 없는 교실에서 파일을 더블클릭해 열어도 됩니다.

- 대상: 중학교 2학년 · 언어: 한국어
- 화면: PC, 전자칠판·TV(16:9), 태블릿(가로·세로), 휴대폰
- 조작: 마우스, 터치(한 손가락 돌리기, 두 손가락 확대), 키보드(`1`~`6` 차례 바꾸기, `←` `→` 단계 이동, `Esc` 창 닫기, `H` 처음 화면)

## 학습 흐름 (교과서 ‘Ⅶ. 별과 우주 – 01 우리은하’ 294~297쪽 순서)

| 차례 | 교과서 | 화면에서 하는 일 |
| --- | --- | --- |
| 1. 도입 | 고구려 벽화 속 견우·직녀, 갈릴레이 | ① 서울 여름밤 하늘에서 직녀성·견우성 사이의 은하수 찾기 ② 망원경 배율을 올려 은하수가 수많은 별로 나뉘어 보이는 것 확인 → “은하수를 이루는 천체는?” |
| 2. 해보기 | 여름철과 겨울철의 은하수 비교하기, 그림 9, 질문 1·2 | ① 우리나라에서 찍은 전천 사진 두 장의 계절 맞히기 ② 같은 시각 여름·겨울 하늘 나란히 비교 ③ 그림 9(옆에서 본 우리은하)에서 A·B·원반 위쪽을 바라본 실제 하늘 보기, 질문 1·2(협력적 소통) |
| 3. 개념: 우리은하의 모양과 크기 | 그림 10, 지름 약 30000 pc, 태양계는 중심에서 약 8500 pc | 위·옆에서 본 3D 우리은하(막대 구조·나선팔·볼록한 원반), 태양계 위치 찾기·은하 공전, 크기 비교, 은하수가 띠로 보이는 까닭(천구 원통), 계절과 지구의 공전, 더 알아보기(자전) |
| 4. 탐구: 우리은하를 구성하는 천체 관측하기 | 천체 관측 프로그램, 지평선 없애기, 검색, 기록표, 정리 1·2, 스스로 평가 | 서울 밤하늘 관측 프로그램에서 ‘설정 → 지평선 없애기’, 교과서 예시 천체(벌집 성단, 큰부리새자리 47, 센타우루스자리 오메가 성단, 보석 상자, 런닝맨 성운, 석탄 포대 성운, 달리는 닭 성운, 초승달 성운, 아이리스 성운) 검색·관측 → 특징과 종류를 골라 기록표 작성(자동 확인) |
| 5. 개념: 성단과 성운 | 그림 11(좀생이성단, NGC 6093, 장미성운, 마귀할멈성운, 말머리성운) | 산개·구상 성단 3D 모형과 밀도 상자, 방출·반사·암흑 성운 사진과 빛의 원리 그림, 성단과 성운 비교 |
| 6. 스스로 확인하기 | 1~3번, 이것만은 꼭 | 고르기·빈칸 문제, 사고력 서술형(핵심어 확인 + 예시 답안), ‘이것만은 꼭’(나선팔) |

각 차례의 문제는 필요한 조작을 먼저 해야 보기가 열리고, 틀리면 힌트, 맞히면 해설이 나옵니다.
수업 진행상 바로 열어야 할 때는 문제 아래 **‘선생님 잠금 해제’**에 암호를 넣습니다(기본 암호: `galaxy`, 아래 ‘선생님 설정’ 참고).
문제 기록은 그 브라우저에만 저장되며, 처음 화면의 ‘기록 모두 지우기’로 지울 수 있습니다.
수치는 교과서 값(우리은하 지름 약 30000 pc ≈ 10만 광년, 태양계–은하 중심 약 8500 pc ≈ 2만 8천 광년)을 따랐습니다.

## 실행 방법

[Node.js](https://nodejs.org/) 20 이상이 필요합니다.

```bash
cd milky-way
npm install
npm run dev        # 개발 서버 → 터미널에 나오는 주소(예: http://localhost:5173)를 브라우저로 열기
```

## 빌드

```bash
npm run build      # dist/index.html 하나가 만들어짐(약 3.5 MB, 사진 포함)
npm run preview    # 빌드 결과 미리 보기
```

`dist/index.html`은 다른 파일이 필요 없습니다. USB에 담아 교실 컴퓨터에서 더블클릭해도 동작합니다.

## 배포 방법 (GitHub Pages)

### 방법 A — 이 저장소(solarsystem)에서 함께 배포 (권장)

‘태양계 탐험’(`index.html`), ‘천체 망원경 관측’(`telescope.html`)과 같은 방식입니다.

```bash
cd milky-way
npm install
npm run publish:root   # 빌드 후 저장소 맨 위에 milkyway.html 로 복사
cd ..
git add milkyway.html milky-way
git commit -m "우리 은하 탐험 업데이트"
git push
```

저장소 **Settings → Pages**에서 *Deploy from a branch*, 브랜치 `main`, 폴더 `/ (root)`로 되어 있으면
`https://<계정>.github.io/solarsystem/milkyway.html` 주소로 열립니다.

### 방법 B — 독립 저장소로 배포

`milky-way` 폴더 내용을 새 저장소의 맨 위에 올리면, 들어 있는 `.github/workflows/deploy.yml`이 `main`에 push할 때마다 자동으로 빌드·배포합니다.
새 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔 주세요. 주소는 `https://<계정>.github.io/<저장소 이름>/`입니다.
`vite.config.js`의 `base: './'`(상대 경로) 덕분에 저장소 이름과 상관없이 동작합니다.

## 선생님 설정

`src/config.js`에서 바꾼 뒤 다시 빌드합니다.

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| `teacherCode` | `galaxy` | 미션 잠금 해제 암호 |
| `summerDate` | 2026년 7월 15일 | 관측 시뮬레이터의 여름 날짜(기상학적 여름의 가운데 달) |
| `winterDate` | 2026년 1월 15일 | 관측 시뮬레이터의 겨울 날짜 |

관측 장소는 서울(북위 37.6°, 동경 127.0°)이며 `src/lib/astro.js`의 `OBSERVER`에서 바꿀 수 있습니다.

## 과학적 근거와 단순화

- 우리은하: 막대나선은하, 원반 지름 약 30000 pc(약 10만 광년), 원반 두께 약 1천 광년, 팽대부 두께 약 1만 광년 이상, 헤일로 지름 20만 광년 이상(경계 흐릿함), 막대 길이 약 2만 7천 광년.
- 태양계: 은하 중심에서 약 8500 pc(약 2만 8천 광년, 교과서 값), 오리온자리 팔(국부 팔). 은하 공전 속도 약 220 km/s, 공전 주기 약 2억 2천만~2억 5천만 년.
- 나선팔 위치: 태양 근처는 별 탄생 영역 관측 결과(Reid 외 2019, *ApJ* 885, 131)의 반지름·감긴 각도를 따르고, 은하 반대편은 같은 나선 모양을 이어 그린 **추정**입니다.
- 태양 주변 천체(플레이아데스, 히아데스, 오리온 대성운, M13, 오메가 센타우리 등)는 실제 은하 좌표와 거리로 배치했습니다.
- 밤하늘: 별 위치·밝기는 예일 밝은 별 목록(BSC5, 6등급까지 5,044개), 별자리 선은 IAU 기준(d3-celestial 자료), 은하수는 ESO 전천 사진을 은하 좌표로 정확히 붙였습니다. 날짜·시각에 따른 별의 위치는 항성시와 좌표 변환으로 계산합니다(세차 운동을 무시해 오차 약 0.5° 이내, 맨눈 관측에는 충분). 대기에 의한 감광, 박명, 광공해를 반영합니다.
- 여름·겨울 은하수 차이는 **은하의 두께가 변하는 것이 아니라 보는 방향(시선 방향의 별·성간 물질 양)이 달라서**임을 화면과 해설에서 강조합니다.
- 크기·거리를 단순화한 화면에는 모두 ‘⚠ 비율 안내’를 표시했습니다(예: 공전 그림의 지구 크기, 성단 모형의 별 수).

## 폴더 구조

```
milky-way/
├─ index.html                 # 앱 진입점
├─ vite.config.js             # 단일 HTML 빌드, 상대 경로(base: './')
├─ scripts/
│  ├─ copy-to-root.mjs        # dist/index.html → ../milkyway.html
│  └─ prepare-sky-data.py     # d3-celestial 자료 → src/data/skyData.js
├─ src/
│  ├─ App.jsx                 # 교과서 차례(SECTIONS), 처음 화면, 키보드, 용어 사전
│  ├─ config.js               # 선생님 설정
│  ├─ store.jsx               # 조작 기록·미션 결과(브라우저 저장)
│  ├─ components/             # 공통 UI(미션, 용어 풀이, 사진, 은하 지도 등)
│  ├─ data/                   # 용어·구조 설명, 별 목록, 사진 목록
│  ├─ lib/                    # 천문 계산(astro), 은하 모형(galaxy), 하늘 투영·사진
│  ├─ sections/               # 도입·그림 9·탐구(관측 프로그램)·스스로 확인하기
│  ├─ modules/m1~m4/          # 3D 은하, 성단·성운, 태양계 위치, 하늘 관측 화면
│  └─ assets/img/             # 사진(빌드할 때 파일 안에 들어감)
└─ .github/workflows/deploy.yml  # 독립 저장소용 자동 배포
```

## 알아 두면 좋은 점

- 3D 그래픽(WebGL)을 쓰므로 최신 크롬·엣지·사파리·웨일에서 열어 주세요. 아주 오래된 기기에서는 3D 화면 대신 안내 문구가 나옵니다.
- 전체 화면 단추(오른쪽 위)를 누르면 TV·전자칠판에서 보기 좋습니다.
